# ОТБОР

Собирает кандидатов из Google Картинок по разметке и даёт выбрать кадр кликом.

## Что получается

```
<Где создать>/<Фамилия> ОТБОР/
    ЦЕЛЕВЫЕ/   запрос.jpg, запрос 2.jpg …     ← выбранные кадры
    ФАКТУРА/   …
    _кандидаты/                               ← рабочее, после ролика — в Корзину
        ЦЕЛЕВЫЕ/<запрос>/01.jpg …, candidates.json
        список.json, отчёт.txt, _страницы/
```

- Кадры называются ровно именем запроса; второй и дальше — «запрос 2», «запрос 3»…
- В папки ЦЕЛЕВЫЕ и ФАКТУРА попадают только jpg и png: webp, avif, heic, gif, tif
  и bmp переводятся в jpg (качество 92) встроенной программой macOS, оригинал удаляется.

## Один раз перед первым запуском

1. Chrome → **«Вид» → «Разработчик» → «Разрешить JavaScript из Apple Events»**.
2. На вопросы macOS «разрешить управлять Chrome / Finder» — разрешить.

## Сбор

1. Впиши фамилию героя и выбери, где создать папку.
2. Вставь ответ с разметкой целиком. Заголовки подсвечиваются синим, строки,
   которые не пойдут в сбор (вступление, ВИДЕО), — зачёркнуты. Справа сводка.
3. «Собрать». Окно Chrome для сбора отдельное — его можно свернуть, но не закрывать.
   Капча → сбор ждёт, Chrome выходит вперёд, звучит сигнал. Прошёл — едет дальше.
4. Повторный «Собрать» пропускает собранное и выбранное.

## Выбор (можно начинать, не дожидаясь конца сбора)

| Действие | Как |
|---|---|
| сделать картинку активной | клик (или стрелки) |
| взять картинку | двойной клик, цифра 1–9 или Enter |
| крупно | пробел — открывает активную; ещё раз пробел или Esc — закрыть |
| обрезать | в крупном просмотре «Обрезать» или C → тяни углы и края, внутри рамки — двигать; пропорции: свободно / 16:9 / 4:3 / 1:1 → Enter |
| вернуть до обрезки | «Вернуть исходник» в крупном просмотре |
| отменить последний выбор | ⌘Z или «Отменить» |
| ещё картинки из той же выдачи | «Ещё 8» |
| своя картинка | «Искать сам» → в Chrome откроется запрос → сохрани картинку в «Загрузки», ОТБОР сам её заберёт |
| ничего не подходит | «Пропустить» — в конце список пропущенных можно скопировать |

Для запросов «по 2 кадра» берёшь две картинки по очереди (✓1, ✓2) — сохраняются
сами. Если подошла только одна — «Готово».

Картинки со значком Google «Licensable» в кандидаты не попадают (в журнале —
«licensable −N»). Первые 5 выдач каждого сбора сохраняются в `_кандидаты/_страницы/`
для проверки.

Тема — кнопка «Светлая/Тёмная» вверху справа.

В конце — кнопка «Кандидатов в Корзину».
